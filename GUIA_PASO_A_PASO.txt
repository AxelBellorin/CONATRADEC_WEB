GUÍA PARA EMPEZAR SIN CONOCIMIENTOS DE BLAZOR
==============================================

1. INSTALAR LO NECESARIO
------------------------
- Abre Visual Studio Installer.
- Busca tu Visual Studio 2022.
- Pulsa Modificar.
- Marca "ASP.NET y desarrollo web".
- En componentes individuales verifica que esté instalado el SDK de .NET 9.
- Pulsa Modificar/Instalar.

2. COLOCAR EL PROYECTO
----------------------
Puedes guardar esta carpeta al mismo nivel que tus otros repositorios:

Proyectos/
├── CONATRADEC/             (aplicación MAUI)
├── CONATRADEC_API/         (backend)
└── CONATRADEC.AdminWeb/    (portal web nuevo)

No tienes que meter el proyecto web dentro del proyecto MAUI.

3. ABRIR EL BACKEND
-------------------
- Abre CONATRADEC_API en Visual Studio.
- Ejecútalo.
- Confirma la dirección, actualmente esperada:
  https://localhost:7176/

4. ABRIR EL PORTAL WEB
----------------------
- Abre CONATRADEC.AdminWeb.csproj.
- Presiona F5.
- Se abrirá el navegador.
- Usa las mismas credenciales de la aplicación.

5. SI LA API TIENE OTRA DIRECCIÓN
---------------------------------
Edita:
appsettings.Development.json

Cambia:
"BaseUrl": "https://localhost:7176/"

por la dirección real que muestre el backend.

6. QUÉ FUNCIONA DESDE AHORA
---------------------------
- Pantalla de login.
- Comunicación con api/auth/login.
- Usuario, rol y permisos.
- Menú adaptable.
- Dashboard base.
- Mapa Leaflet.
- Diseño para computadora, tablet y móvil.

7. QUÉ HAREMOS DESPUÉS
----------------------
ETAPA 2 - Backend:

- Endpoint liviano de mapa.

ETAPA 3 - Portal:

8. REGLA IMPORTANTE
-------------------
No guardaremos fotografías pesadas dentro del dashboard.
No cargaremos análisis completos para pintar el mapa.
La API devolverá respuestas resumidas para mantener MonsterASP.NET rápido.
