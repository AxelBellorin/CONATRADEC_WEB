ACTUALIZACIÓN: USUARIOS + BITÁCORA + MAPA DEPARTAMENTAL
=======================================================

FORMA MÁS SENCILLA
------------------
Esta carpeta contiene el proyecto web completo actualizado.

1. Cierra Visual Studio.
2. Haz una copia de seguridad de tu carpeta CONATRADEC.AdminWeb actual.
3. Copia todos los archivos de esta entrega y reemplaza los existentes.
4. Conserva tu archivo CONATRADEC.AdminWeb.slnx si ya lo creaste.
5. Borra las carpetas bin y obj.
6. Abre CONATRADEC.AdminWeb.slnx o CONATRADEC.AdminWeb.csproj.
7. Compila y ejecuta.

NO HAY CAMBIOS EN EL BACKEND
----------------------------
Esta actualización usa los endpoints que ya existen:

GET api/usuarios/listar
GET api/bitacora
GET api/bitacora/catalogos
GET api/bitacora/{id}
GET api/mapa/terrenos

La bitácora envía automáticamente el encabezado X-Usuario-Id usando el usuario
que inició sesión.

MAPA DE DEPARTAMENTOS
---------------------
Los límites se consultan desde el servicio público GeoJSON de UNICEF y se pintan
con Leaflet. No requiere Google Maps, claves API ni tablas nuevas.

Se necesita acceso a Internet para descargar el mapa base de OpenStreetMap y los
límites departamentales. Los terrenos continúan viniendo desde tu API local.

PRUEBA RECOMENDADA
------------------
1. Ejecuta el backend en https://localhost:7176/
2. Confirma que funcionan en Swagger:
   - api/usuarios/listar
   - api/bitacora/catalogos enviando X-Usuario-Id
   - api/mapa/terrenos
3. Ejecuta el portal web.
4. Inicia sesión con un usuario que tenga permiso bitacoraPage para abrir Bitácora.
